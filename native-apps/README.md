# Native calculator apps

This folder contains the source projects for the native editions of the Glassmorphism Calculator.

## Android

Download `android-native-project.zip` and extract it. Open the extracted project folder in Android Studio, allow Gradle to sync, and run the `app` configuration on an emulator or connected device.

- Kotlin and Jetpack Compose
- JDK 17 and Android SDK 35 or newer
- Minimum Android version: API 24

## iOS

Download `ios-native-project.zip` and extract it on a Mac. Open `GlassCalculator.xcodeproj` in Xcode, select a simulator or device, and run the `GlassCalculator` scheme.

- Swift and SwiftUI
- Xcode 16 or later
- Minimum iOS version: iOS 17

The archives contain source projects, not installable APK or App Store packages. iOS builds require macOS and Xcode.
