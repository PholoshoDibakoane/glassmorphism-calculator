# Glassmorphism Calculator


A responsive calculator with a dark glassmorphism interface, built with vanilla HTML, CSS, and JavaScript. The layout adapts to phone screens and supports touch-friendly controls.


## Features


- Addition, subtraction, multiplication, and division
- Decimal input, clear, and delete controls
- Operator precedence and negative numbers
- Responsive layout with mobile safe-area support
- Handles invalid expressions and division by zero


## Run locally


1. Download or clone this repository.
2. Open `index.html` in a modern browser.


No build tools or dependencies are required.


## Project files


- `index.html` — calculator structure and controls
- `style.css` — glassmorphism theme and responsive layout
- `script.code.js` — calculator input and arithmetic logic


## Compatibility


Works in modern desktop and mobile browsers, including Safari on iOS and Chrome on Android. This repository currently contains the web version; a native mobile app is a separate next step.
